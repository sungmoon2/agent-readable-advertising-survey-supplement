# S2 Targeted Verification Note

Created: 2026-05-17

## Purpose

This note documents a targeted verification check for selected high-risk interpretive coding records in the survey supplement.

The check was added after the codebook and claim-to-citation matrix were prepared. Its purpose is to improve traceability for corpus-bounded negative claims and boundary-sensitive coding decisions.

## Scope

The verification covers two groups:

- 15 C1-C6 core-paper records selected for claim impact, boundary ambiguity, near-counterexample risk, or dependence on multiple interpretive fields.
- 19 C7/C8 infrastructure-source rows checked separately because C7/C8 are standards/protocol corpora rather than C1-C6 research-paper clusters.

The detailed record-level table is provided in `S2_targeted_verification_detail_S260517t.csv`.

The descriptive outcome summary is provided in `S2_targeted_verification_outcome_summary_S260517t.csv`.

## Verification Mode

The check was label-visible: the verifier had access to the existing coding records while checking the selected records against the relevant source material and coding rules.

Because original labels were visible and the sample was claim-impact-based rather than randomly drawn for reliability estimation, this procedure should be interpreted as targeted verification, not independent second coding.

## Outcome Categories

- `confirmed`: existing coding and claim-impact interpretation were retained.
- `revised`: one or more coding fields or claim-impact notes were changed.
- `discussion-needed`: the record required further author discussion before final treatment.

In the S260517t public table, all 34 selected records are recorded as `confirmed`; no field revisions or manuscript/supplement changes were recorded in the signoff table.

## Methodological Boundary

This targeted verification is a descriptive traceability and robustness check. It does not report or imply:

- independent double coding;
- blind recoding;
- inter-rater reliability;
- Cohen's kappa;
- Jaccard agreement;
- agreement rate;
- adjudication;
- independent audit;
- external validation;
- non-core validation.

Negative claims supported by this supplement remain corpus-bounded claims: they mean that the reviewed corpus and associated coding records did not identify a system, benchmark, defense, standard, or protocol satisfying the specified condition.
